# Turtle Shot: Underwater Golf

A sideways Android game: Betito the turtle is the ball. Slingshot him through a flooded maze to the glowing hole in as few shots as you can.

## How to play
- When he's stopped (green ring), touch anywhere, pull back, let go. The ring around him is the power gauge; the dashed circle shows how far the shot glides in still water.
- Currents are boost lanes. Ride several in one shot for combos: NICE!!, DEADLY COMBO!!, KING OF THE SEA!!
- Hit a buoy to flip its current. Gold locks open shortcut gates, pink stars are bonus points, kelp slides whip you around corners, seaweed stops you, sharks bump your shots.
- Octo the octopus (Betito's caddie) explains each new thing the first time it shows up. The full list is in **How to play** on the start screen and **Item guide** in the pause menu.
- Golf scoring: par, birdie, eagle, albatross, hole in one, plus a speed bonus. Apples and big combos spin the slot reels.

## Install a test build
Open the Actions tab, tap the latest **Build APK** run, download **screen-skater-apk**, and install it.

Note: the app ID changed to `com.betmor.lilbetito` for the Play Store, so this installs as a new app next to the old overlay version. Uninstall the old one.
